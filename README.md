# Lead Management System (Full Stack)

Personal full-stack project demonstrating RESTful API design using Java
Spring Boot and API documentation using Swagger UI.

## Tech Stack
- Java 8
- Spring Boot
- REST APIs
- Spring Data JPA
- MySQL
- Swagger UI

## Features
- Create and retrieve leads
- RESTful architecture
- Layered backend design
- API documentation using Swagger

## API Sample
GET /api/leads
